<glass-toggle>

玻璃质感通用二态开关 —— 由日夜专用组件泛化而来，玻璃折射、磨砂与 LED 散射光学 1:1 保留。 默认即中性通用形态：深色圆角底板（可嵌任意页面背景）+ 点阵电源符 + 绿(开)/灰(关)灯光； 首屏的日/夜场景只是一条 preset="day-night" 预设。零依赖 Web Component，支持点击、拖拽、键盘与受控使用。

快速开始

<script type="module" src="./glass-toggle.js"></script>

<!-- 通用默认：plinth 底板 + 电源符，任意页面直接放 -->
<glass-toggle style="width:560px;height:360px"></glass-toggle>

<!-- 日/夜场景预设：全屏环境底 + 页面明暗联动 -->
<glass-toggle preset="day-night" style="width:100vw;height:100vh"></glass-toggle>

变体一览

属性（Attributes）

属性类型通用默认说明
checkedbooleanfalse初始/受控状态；JS 内外修改均生效并反映回特性
on-icon / off-iconstringpower / power开/关态图标：内置名、像素串或 1–2 字符 emoji
on-color / off-color#rrggbb#34d399 / #7c8598开/关态灯光颜色
theme"auto"|"dark"|"light"dark表面明暗：固定，或 auto 跟随开关位置（日/夜行为）
surface"plinth"|"scene"plinth圆角底板+透明羽化边（可嵌任意页面）；或全场景环境底色
preset"day-night"—一键日/夜：scene + auto + sun/moon + 琥珀/月蓝；显式属性优先
disabledbooleanfalse禁用交互、灯光转暗
path"glass"|"track""glass"光带路径：贴把手环绕 / 沿容器内壁环绕
zoomnumber1相对自适应尺寸的放大倍数（最小 0.5）
hintstring自动底部提示文字；"none" 隐藏
labelstring—无障碍 aria-label

属性（Properties / 方法）与事件

成员说明
el.checked: boolean读写当前开关状态
el.toggle()切换开关
change 事件切换后触发，detail.checked 为新状态；可组合、可冒泡
themechange 事件仅 theme="auto"：表面明暗跨界（滑过中点）时触发，detail.lit

交互

点击轨道任意处切换；按住玻璃把手可拖拽（可越过端点回弹）；键盘：聚焦后 Space / Enter / ← / → 切换。 组件带 role="switch" 与 aria-checked。

在框架中使用

// React 18+（CustomEvent 不走合成事件，用原生 addEventListener）
import "./glass-toggle.js";

<glass-toggle ref={ref} />
useEffect(() => {
  const el = ref.current;
  const onChange = e => setChecked(e.detail.checked);
  el.addEventListener("change", onChange);
  return () => el.removeEventListener("change", onChange);
}, []);
<!-- Vue 3：main.js 里 import 一次即可 -->
<glass-toggle :checked="on" @change="on = $event.detail.checked" />
